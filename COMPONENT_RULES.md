## Regla 1 — Referencia el showcase primero

Antes de crear cualquier componente, abrí `/showcase` (`src/app/(brand)/showcase/`).
Si el componente que necesitás ya existe ahí, usá esa variante exacta.
No inventes variantes nuevas sin actualizar primero `brand.json.component_rules`
y el showcase. El showcase es la verdad renderizada; este archivo es la verdad escrita.

## Regla 2 — Tokens de color, nunca hex

Los colores viven como CSS vars en `brand/brand.css`. Se consumen como
arbitrary values de Tailwind — nunca hex inline, nunca clases de color Tailwind.

```
Correcto:   className="bg-[var(--color-primary)] text-white"
            className="text-[var(--color-text-muted)] border-[var(--color-border)]"
Incorrecto: className="bg-[#3B82F6] text-white"        ← hex inline
            className="bg-blue-500 text-gray-800"        ← clases Tailwind de color
            style={ background: '#6366F1' }              ← hex en style prop
```

Tokens disponibles (1:1 con `brand.json.tokens.colors`):

```
--color-primary           --color-primary-deep      --color-accent
--color-secondary         --color-surface           --color-surface-elevated
--color-border            --color-text              --color-text-muted
--color-text-subtle       --color-success           --color-danger
--color-warning           --color-info
```

Si necesitás un color que no está acá, agregá el token a `brand.json` primero —
no lo hardcodees.

## Regla 3 — Fuente del proyecto

La fuente body es `Geist` y la display es
`Geist`. **Nunca** las cambies a Inter, Roboto,
o Arial. Se consumen vía CSS var, nunca por nombre literal:

```
Correcto:   className="font-[family-name:var(--font-body)]"
            className="font-[family-name:var(--font-display)]"
Incorrecto: className="font-inter"   /  style={ fontFamily: 'Roboto' }
```

Para texto monoespaciado (código, tokens, métricas técnicas) usá
`font-[family-name:var(--font-mono)]` (`Geist Mono`).

## Regla 4 — Motion system

Importá presets del módulo de motion del proyecto — nunca hardcodees duraciones
ni curvas de easing inline:

```ts
import { MOTION, DURATION, EASING, SAFE, UNSAFE } from '@/brand/motion'
```

O usá las duraciones como arbitrary values directo de las CSS vars:
`duration-[var(--motion-duration-fast)]`, `ease-[var(--motion-easing)]`.

Duraciones (1:1 con `brand.json.motion.durations_ms`):
`--motion-duration-instant` · `--motion-duration-fast` ·
`--motion-duration-base` · `--motion-duration-slow`.

**Animá SOLO** (props baratas, compositor-friendly — `SAFE`):
`transform`, `opacity`, `color`, `background-color`, `border-color`, `box-shadow`.

**NUNCA animes** (causan reflow/layout shift — `UNSAFE`):
`width`, `height`, `padding`, `margin`, `top`, `left`.

`brand.css` ya zeroa las duraciones bajo `prefers-reduced-motion` — respetalo,
no lo sobreescribas.

## Regla 5 — Los 4 estados obligatorios

Todo componente que carga datos debe implementar los 4 estados — ninguno opcional:

1. **Loading** — skeleton que imita el layout real (no spinner genérico). Usá
   `bg-[var(--color-surface-elevated)]` para el placeholder.
2. **Error** — mensaje textual con `text-[var(--color-danger)]` + botón retry.
3. **Empty** — heading + descripción + CTA (ver Regla 10).
4. **Data** — el render principal.

Un componente que solo maneja el happy path (Data) está incompleto y se rechaza.

## Regla 6 — Iconografía

Solo **Lucide React** (outline series). Nunca mezclar con Heroicons, FontAwesome,
emojis-como-íconos, u otras librerías.

Tamaños canónicos:

```
h-4 w-4   inline (dentro de texto / botones con label)
h-5 w-5   navegación (sidebar / topbar / tabs)
h-6 w-6   standalone (acción aislada / empty state)
```

El color del ícono hereda del texto (`currentColor`) o usa un token
(`text-[var(--color-text-muted)]`), nunca un hex.

## Regla 7 — Accesibilidad no negociable

- Botones icon-only → `aria-label` descriptivo obligatorio.
- Inputs → `label` asociado por `htmlFor` ↔ `id` (no placeholder-as-label).
- Focus visible SIEMPRE → nunca `outline-none` sin un ring equivalente
  (`focus-visible:outline-2 focus-visible:outline-[var(--color-primary)]`).
- Botones en loading → `disabled` + `aria-busy={isLoading}`.
- Contraste body ≥ 4.5:1, texto grande ≥ 3:1 (`brand.json.validation`).

## Regla 8 — Variantes canónicas de Button

Solo estas 4 variantes (`brand.json.component_rules.button.variants`):

```
primary     bg-[var(--color-primary)] text-white          ← CTA principal
secondary   border-[var(--color-border)] bg-[var(--color-surface)]
ghost       sin fondo, hover:text-[var(--color-text)]
danger      bg-[var(--color-danger)] text-white            ← acción destructiva
```

- No crear variantes custom con `className` ad-hoc.
- **Máximo 1 botón primary por pantalla** — el resto secondary / ghost.
- Sin gradientes diagonales en primary (anti-slop). Fondo sólido.
- Estados requeridos por variante: focus, hover, active, disabled, loading.

## Regla 9 — Cards

Variantes (`brand.json.component_rules.card.variants`):

```
default       border-[var(--color-border)] bg-[var(--color-surface)]   ← listas, contenido estático
interactive   default + hover state (transition-colors)                ← clickable / linkable
metric        default + número display grande                          ← KPIs, dashboards
empty         estado vacío (ver Regla 10)
```

- En UI oscura, preferí border o surface antes que shadow pesado.
- Sin `rounded-3xl` + `shadow-2xl` (patrón slop): usá `rounded-[var(--radius-md)]`.
- **No anidar Cards** dentro de otras Cards.
- Una Card debe agrupar, comparar, ejecutar o revelar — si no hace nada de eso,
  no es una Card, es un `div`.

## Regla 10 — Empty States

Cada componente con datos tiene su propio empty state — no uno genérico compartido:

- La ilustración/ícono debe ser temáticamente relacionado con el tipo de
  contenido vacío (Lucide acorde al dominio, h-6 w-6).
- Estructura: ícono + heading (`font-[family-name:var(--font-display)]`) +
  descripción breve (`text-[var(--color-text-muted)]`) + CTA.
- El CTA del empty state es la **acción principal que crea el primer elemento**
  (no un "volver" pasivo).
- El copy sigue `voice.json` — directo, sin hype ni `avoid_words`.
