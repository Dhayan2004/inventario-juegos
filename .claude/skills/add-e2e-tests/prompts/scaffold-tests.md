## Protocolo

### Paso 1 — Crear estructura

```
tests/e2e/
├── auth.setup.ts          ← de templates/auth.setup.ts.template
├── example.spec.ts         ← de templates/example.spec.ts.template
└── helpers/
    └── auth.ts            ← de templates/helpers-auth.ts.template
playwright/
└── .auth/
    └── .gitkeep           ← marker para storageState directory
```

- Cada archivo es un Write desde su template correspondiente.
- NO substituir variables agresivamente — los templates están escritos como código directo, no Jinja-style.

### Paso 2 — Extender `.gitignore`

Append (solo si NO existen ya — grep antes de append):

```
# Playwright (managed by add-e2e-tests)
playwright/.auth/*.json
test-results/
playwright-report/
```

- Read `.gitignore` actual.
- Para cada línea de las 3 → grep `^playwright/.auth/\*.json\b\|^test-results/\b\|^playwright-report/\b`. Si match → skip.
- Si ninguna entry existe → append el bloque completo con header de comentario.
- Si `.gitignore` no existe → crear con el bloque + header `# Generated by Forja`.

### Paso 3 — Extender `package.json` scripts

Read `package.json`. Para cada script nuevo:

| Script | Comando |
|--------|---------|
| `test:e2e` | `playwright test` |
| `test:e2e:ui` | `playwright test --ui` |
| `test:e2e:debug` | `playwright test --debug` |

Lógica:
- Si la key existe en `scripts` → skip (NO overwrite, el usuario puede tener custom config).
- Si NO existe → agregar al objeto `scripts`.
- Preservar formato (indent 2 spaces canónico npm, trailing newline al final del JSON).
- Validar post-write con `node -e "JSON.parse(require('fs').readFileSync('package.json','utf8'))"`. Si falla → revertir con `git restore package.json` (si está en repo) y halt.

### Paso 4 — Sanity check

```bash
# Verificar que los specs parsean como TypeScript válido
npx tsc --noEmit --jsx preserve --moduleResolution bundler --module esnext --target es2022 tests/e2e/auth.setup.ts tests/e2e/example.spec.ts tests/e2e/helpers/auth.ts
```

- Exit 0 esperado.
- Si fail → reportar errores, revertir los Writes en tests/e2e/, halt.

## Refusals

- ❌ Sobrescribir specs existentes en `tests/e2e/**/*.spec.ts`.
- ❌ Overwrite scripts ya definidos en `package.json` (anti-patrón E-009 causa 2 — pérdida de customización).
- ❌ Modificar `.gitignore` sin verificar que las entries no existen ya.
- ❌ Asumir que el usuario tiene la estructura `tests/` ya — crear si no existe (mkdir -p equivalente vía Write).
