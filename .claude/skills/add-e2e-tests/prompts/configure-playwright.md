# configure-playwright — playwright.config.ts generation

> Prompt operativo. Invocado por add-e2e-tests Fase 2.
> **Cita:** `[memory:CONSTRAINTS.md#R13]` (find-docs antes de Playwright config),
> `[memory:decisions#D-026]` (BINARY mode determina `projects` array),
> `[docs:playwright]`, `[docs:playwright-test]`.

---

## Precondiciones

- Mode determinado (`minimal` o `full`).
- find-docs corrió contra `playwright` para validar config schema actual.
- `playwright.config.ts` NO existe en el target (si existe → halt + diff, este prompt NO corre).

---

## Protocolo

### Paso 1 — Read template

```
Read .claude/skills/add-e2e-tests/templates/playwright.config.ts.template
```

### Paso 2 — Resolver variables del template

| Variable | Resolución |
|----------|------------|
| `{{ baseURL }}` | `process.env.NEXT_PUBLIC_APP_URL \|\| 'http://localhost:3000'` (string inline en config) |
| `{{ projects }}` | minimal → 1 project (Chromium). full → 3 projects (Chromium + Firefox + WebKit). Cada project con `storageState: 'playwright/.auth/user.json'` y dependency en `setup` project |
| `{{ workers }}` | `process.env.CI ? 1 : undefined` (en CI 1 worker para flake reduction, local paralelo por defecto) |
| `{{ retries }}` | `process.env.CI ? 2 : 0` |
| `{{ webServerCommand }}` | `'npm run dev'` (override via env `E2E_WEB_SERVER_COMMAND` si está seteado) |
| `{{ webServerPort }}` | `3000` |

### Paso 3 — Write playwright.config.ts en raíz del proyecto

- Path: `<project-root>/playwright.config.ts` (NO bajo `tests/`).
- Header del archivo cita:
  ```
  // Generated by add-e2e-tests. [memory:decisions#D-026] · [docs:playwright]
  ```

### Paso 4 — Validación post-write

```bash
# Sanity check de TypeScript parse (no full typecheck)
node -e "require('typescript').transpileModule(require('fs').readFileSync('playwright.config.ts','utf8'), { compilerOptions: { module: 'commonjs' }})"
```

- Exit 0 esperado.
- Si falla → reportar el error, revertir el write (`git restore playwright.config.ts` si está en repo, o `rm` si es nuevo) y halt.

### Paso 5 — Validación de mode

- minimal → grep `Firefox\|firefox\|WebKit\|webkit` en playwright.config.ts → debe retornar 0 matches.
- full → grep `Firefox\|firefox\|WebKit\|webkit` en playwright.config.ts → debe retornar ≥2 matches.

## Defaults del config canónico Forja

| Campo | Valor | Razón |
|-------|-------|-------|
| `testDir` | `'./tests/e2e'` | Convención Forja. Carpeta dedicada, no mezclar con unit tests. |
| `fullyParallel` | `true` | Específicos individuales aislados. Auth state via `storageState`, no shared mutable state. |
| `forbidOnly` | `!!process.env.CI` | En CI fallar si quedó `.only`; local permitido. |
| `retries` | `process.env.CI ? 2 : 0` | Local no retry (debugging directo). CI 2 retries para mitigar flake de network. |
| `workers` | `process.env.CI ? 1 : undefined` | CI single worker (Vercel free tier shared CPU). Local paralelo automático. |
| `reporter` | `[['html', { open: 'never' }], ['list']]` | HTML para post-mortem, list para CI stdout. |
| `timeout` | `30 * 1000` | 30s por test. |
| `expect.timeout` | `5 * 1000` | 5s por `expect()`. |
| `use.baseURL` | resolved | `process.env.NEXT_PUBLIC_APP_URL \|\| 'http://localhost:3000'`. |
| `use.trace` | `'on-first-retry'` | Trace viewer solo cuando retry — balance tamaño/utilidad. |
| `use.screenshot` | `'only-on-failure'` | Captura solo en fail. |
| `webServer.command` | `'npm run dev'` | Reuse del dev server local. |
| `webServer.port` | `3000` | Convención Next.js. |
| `webServer.reuseExistingServer` | `!process.env.CI` | Local reusa el server si ya está corriendo; CI siempre arranca uno fresh. |

## Refusals

- ❌ Generar config sin invocar find-docs antes (R13 violation).
- ❌ Sobrescribir `playwright.config.ts` existente — el SKILL.md ya hizo halt+diff antes de llegar a este prompt.
- ❌ Hardcodear `baseURL` sin fallback a `process.env`.
- ❌ Setear `workers: undefined` en CI (race conditions en Vercel free tier).
