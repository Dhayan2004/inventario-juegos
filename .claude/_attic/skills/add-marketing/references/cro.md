# cro — Optimización de conversión para páginas de marketing (home, landing, pricing, features, formularios)
> Destilado de coreyhaines31/marketingskills (MIT) · skill original: cro · fetched 2026-08-18

## Initial assessment (before any recommendation)
Read the product-marketing context (see product-marketing.md) if available, then identify:
1. **Page type** — homepage, landing page, pricing, feature page, form
2. **Primary conversion goal** — sign up, demo request, purchase, lead capture
3. **Traffic context** — where visitors come from (ads, organic, email, referral)

## Analysis framework (ordered by impact)
1. **Value proposition clarity** — 5-second test: what is it, who is it for, why care.
   Benefits over features, customer language, no vagueness/jargon/overload.
2. **Headline effectiveness** — communicates core value; matches traffic-source
   messaging. Strong patterns: outcome-focused · specific (numbers/details) ·
   social-proof-based.
3. **CTA placement, copy, hierarchy** — single primary action above the fold;
   benefit-driven button copy ("Start Free Trial", never "Submit"); clear
   primary/secondary structure; repeat CTA at decision points.
4. **Visual hierarchy & scannability** — key elements prominent, white space,
   images that support (not distract from) the message.
5. **Trust signals & social proof** — customer logos, testimonials, case-study
   numbers, review scores; position near CTAs and benefit claims.
6. **Objection handling** — price, "will it work for me", implementation effort,
   risk. Tools: FAQ, guarantees, comparisons, process transparency.
7. **Friction points** — excessive form fields, unclear steps, mobile issues,
   slow load times.

## Deliverable structure
- **Quick Wins** — easy, immediate-impact changes
- **High-Impact Changes** — prioritized bigger efforts
- **Test Ideas** — A/B hypotheses (see ab-testing.md)
- **Copy Alternatives** — 2-3 options for key elements

## Form optimization (essentials)
- Every field must earn its place; fewer fields → higher completion.
- Multi-step forms: easy questions first, progress indicator.
- Inline validation and clear error handling.

## Discovery questions
1. Current conversion rate and target?
2. Traffic sources?
3. What happens after the page (flow)?
4. Any user research / heatmaps / session recordings?
5. What has been tried before?
