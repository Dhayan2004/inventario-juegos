# copywriting — Copy persuasivo para páginas web (home, landing, pricing, features) enfocado en claridad y conversión
> Destilado de coreyhaines31/marketingskills (MIT) · skill original: copywriting · fetched 2026-08-18

## Writing principles
- **Simple over complex** — accessible language, no jargon.
- **Specificity over vagueness** — ban empty verbs like "streamline", "optimize";
  use concrete outcomes, numbers, timeframes.
- **Active voice, confident tone** — no hedging or unnecessary qualifiers.
- **Show outcomes** rather than describe features.
- Quality pass: cut jargon, trim run-on sentences, remove qualifiers and
  exclamation points.

## Pre-writing context (gather before drafting)
1. **Page purpose** — page type and the one action you want taken
2. **Audience** — who they are, their problem, objections, the words THEY use
3. **Product/offer** — differentiation, transformation promised, proof points
4. **Traffic context** — source and visitor knowledge level (cold vs warm)

Read product-marketing.md context first if available — especially the Customer
Language and Brand Voice sections.

## Page structure framework
| Element | Function |
|---|---|
| Headline | Core value proposition; specific beats generic |
| Subheadline | Expansion, 1-2 sentences |
| Primary CTA | Action-oriented; communicates benefit |
| Social proof | Credibility (logos, testimonials, numbers) |
| Problem section | Demonstrate understanding of the pain |
| Solution/benefits | 3-5 items, each tied to an outcome |
| How it works | 3-4 steps that simplify complexity |
| Objection handling | FAQ, comparisons, guarantees |

## CTA formula
**[Action verb] + [What they get] + [Qualifier if needed]**
Examples: "Start Free Trial" · "Get the Complete Checklist".
Never label-only buttons ("Submit", "Learn More" as primary CTA).

## Headline patterns (strong)
- Outcome-focused ("Ship your site in a weekend")
- Specific with numbers/details
- Social-proof-based ("Join 12,000 teams that...")
