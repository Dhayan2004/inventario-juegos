# onboarding — Optimización de activación post-signup: aha moment, time-to-value y recuperación de usuarios estancados
> Destilado de coreyhaines31/marketingskills (MIT) · skill original: onboarding · fetched 2026-08-18

## Initial assessment
Read product-marketing.md context first. Then understand:
1. Product type (B2B/B2C) and core value proposition
2. **Activation definition** — which action signals the "aha moment"?
3. Current state — post-signup experience and where users drop off

## Core principles
1. **Time-to-value is everything** — eliminate friction between signup and value.
2. **One goal per session** — one successful outcome; defer advanced features.
3. **Do, don't show** — interactive action beats tutorials.
4. **Progress creates motivation** — visible advancement, milestone celebration.

## Defining activation
Find the action that correlates strongest with retention (retained users do it,
churned users skip it; earliest predictor). Examples: project mgmt = create
project + add teammate · analytics = install tracking + view first report ·
design tool = create + export/share · marketplace = first transaction.
Track: signup→activation %, time to activation, steps to activation, rate by
cohort/source.

## First 30 seconds post-signup
| Approach | Best for | Pitfall |
|---|---|---|
| Product-first | simple/B2C/mobile | blank-canvas overwhelm |
| Guided setup | personalization-dependent | friction before value |
| Value-first (demo data) | products that can pre-populate | "not real" feeling |
Always: single unambiguous next action · no dead ends · progress indicator.

## Onboarding checklist pattern
Use when multiple setup steps or self-serve B2B. Rules: 3-7 items max · order by
impact, quick wins early · progress bar + % · celebrate completion · dismissible.

## Empty states
Turn dead ends into onboarding: explain the section's purpose · show what the
populated state looks like · prominent primary action · optional example data.

## Tooltips / tours
Only for complex or non-obvious UI. Max 3-5 steps · dismissible anytime · never
repeat for returning users.

## Email + in-app orchestration
Triggers: welcome (immediate) · incomplete onboarding (24h, 72h) · activation
milestone (celebrate + next step) · feature discovery (day 3, 7, 14).
Emails reinforce in-app actions, don't duplicate them; specific CTAs back into
the product; personalize by actions taken.

## Stalled user recovery
Define "stalled" operationally (X days inactive, setup incomplete). Tactics:
email sequence (value reminder, obstacle ID, help offer) · in-app welcome-back +
resume checkpoint · human outreach for high-value accounts.

## Measurement
Activation rate · time to activation · onboarding completion % · D1/D7/D30
retention. Funnel: `Signup 100% → Step1 80% → Step2 60% → Activation 40% →
Retention 25%` — attack the largest drop-off first.

## Output formats
Audit: Finding → Impact → Recommendation → Priority.
Flow design: activation goal · step-by-step flow · checklist items · empty-state
copy · email triggers · metrics plan.
