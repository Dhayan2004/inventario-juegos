# copy-editing — Edición sistemática de copy existente en 7 pasadas secuenciales, preservando la voz del autor
> Destilado de coreyhaines31/marketingskills (MIT) · skill original: copy-editing · fetched 2026-08-18

## Philosophy
Enhance, don't rewrite. Preserve the author's voice and core message. Run the
seven sweeps in order — each pass addresses ONE dimension.

## The Seven Sweeps
1. **Clarity** — reader understands the message: eliminate confusing structures,
   unclear pronouns, unexplained jargon, buried points.
2. **Voice and Tone** — consistency of personality and mood; read aloud to catch
   jarring formal/casual shifts.
3. **So What** — every claim connects to a reader benefit; bridge features to
   consequences by asking "why should I care?" of each statement.
4. **Prove It** — every claim needs evidence: testimonials, data, third-party
   validation, risk reversals. Flag unsupported assertions.
5. **Specificity** — replace vague language with concrete numbers, timeframes,
   examples. Kill generic statements that could apply to any product.
6. **Heightened Emotion** — add texture: sensory language, micro-stories, vivid
   "before" states. Never cross into manipulation.
7. **Zero Risk** — remove friction near CTAs: address objections, add trust
   signals, clarify the next step.

## Word-level tools
- Cut filler: "very", "just", "actually", unnecessary qualifiers.
- Plain-English replacements: utilize→use, leverage→use, etc.
- Sentence caps: max ~25 words, one idea per sentence.
- Problem/fix pairs: feature overload → benefits; weak opening → lead with the
  point; buried CTA → surface it.

## Expert panel scoring (high-stakes copy)
- Assemble 3-5 relevant personas (e.g. conversion copywriter, target customer,
  brand strategist).
- Each scores the copy 1-10 on their expertise.
- Target: **7+ individually, 8+ average**. Revise and re-score until met.
