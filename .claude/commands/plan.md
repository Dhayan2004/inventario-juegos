# /plan

Lee y ejecuta `.claude/skills/la-herreria/SKILL.md`.

`la-herreria` orquesta el pipeline de planificación (Mode Selector + 10 fases: Viability → BMC/VPC → PDR → Tech Spec → UX Research → User Stories → UX Design → UI Design Workflow → Security Audit → Master Blueprint).

**Output esperado:** `BLUEPRINT-<nombre>.md` o `AI-FEATURE-BRIEF-<nombre>.md` aprobado por el usuario.

**Siguiente paso sugerido al cerrar:** `/crisol` (validación estratégica) o `/build` (ejecución directa).
